# Домашнее задание: Kubernetes

## Ответы на вопросы

**Что такое k8s?**
Система, которая управляет контейнерами на группе серверов: запускает их, масштабирует, обновляет и перезапускает, если что-то упало.

**В чём преимущество контейнеризации над виртуализацией?**
Контейнеру не нужна своя гостевая ОС, он использует ядро хоста. Поэтому он легче, запускается за секунды и занимает меньше ресурсов, чем виртуальная машина.

**В чём состоит принцип самоконтроля k8s?**
Мы описываем, как должно быть (например, «2 реплики»), а k8s сам следит за фактическим состоянием и исправляет расхождения: упавший под он просто создаёт заново.

**Зачем понимать принципы деплоя в k8s?**
Чтобы самому выкатывать модели и сервисы, не ждать DevOps по каждой мелочи и уметь обновлять и откатывать версии без простоя.

**Какое средство управления секретами наиболее распространено с k8s?**
HashiCorp Vault. Встроенные Secret хранят данные только в base64, этого для серьёзных задач мало.

**Какие типы нод есть в k8s, каковы их функции?**
- **Master** (control plane) управляет кластером: принимает команды (API server), хранит состояние (etcd), решает, на какой ноде запустить под (scheduler), и следит за желаемым состоянием (controller manager).
- **Worker** запускает сами приложения: kubelet управляет подами на ноде, kube-proxy отвечает за сеть, container runtime запускает контейнеры.

## Манифест

Файл [deployment.yaml](deployment.yaml):

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: netology-ml
spec:
  replicas: 2
  strategy:
    type: RollingUpdate
    rollingUpdate:
      maxUnavailable: 1
      maxSurge: 1
  selector:
    matchLabels:
      app: netology-ml
  template:
    metadata:
      labels:
        app: netology-ml
    spec:
      containers:
        - name: tomcat
          image: tomcat:8.5.69
          ports:
            - containerPort: 8080
```
